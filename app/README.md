# CardRank

Локальный одностраничный редактор рейтингов Love and Deepspace. Состояние рейтинга, фильтры, поиск, сортировка и выбранные настройки интерфейса сохраняются в `localStorage` этого браузера. Сервер и учётная запись не нужны.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки: `npm run build`. Каталог карточек находится в `app/cards.json`. Изображения хранятся отдельно в `../assets/memories`; Vite копирует их в сборку. Это разделение позволяет позже вынести `assets` в отдельный репозиторий.

Чтобы использовать внешний каталог изображений, задайте `VITE_ASSET_BASE_URL` при запуске или сборке. Значение должно указывать на каталог с файлами WebP, например `https://example.com/memories/`.

Поле `image` содержит только имя файла; адрес изображения централизован в `src/catalog.ts`. Формат мифовых записей импортёра нормализуется там же в объект `myth` для приложения. Скрипт импорта и его инструкции находятся в `../CardImporter`.
