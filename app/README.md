# CardRank

Локальный одностраничный редактор рейтингов Love and Deepspace. Состояние рейтинга, фильтры, поиск, сортировка и выбранные настройки интерфейса сохраняются в `localStorage` этого браузера. Сервер и учётная запись не нужны.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки: `npm run build`. Приложение сейчас читает тестовый каталог из `../CardImporter/standalone/output/cards.json`, а Vite берёт изображения из `../CardImporter/standalone/output/images` и копирует их в сборку рядом с приложением. Этот каталог пока изолирован от основного каталога карточек и содержит только импортированные записи.

Чтобы использовать внешний каталог изображений, задайте `VITE_ASSET_BASE_URL` при запуске или сборке. Значение должно указывать на каталог с файлами WebP, например `https://example.com/memories/`.

Поле `image` содержит только имя файла; адрес изображения централизован в `src/catalog.ts`. Формат мифовых записей импортёра нормализуется там же в `myth` объект для приложения.
