# CardRank

Локальный одностраничный редактор рейтингов Love and Deepspace. Состояние рейтинга, фильтры, поиск, сортировка и выбранные настройки интерфейса сохраняются в `localStorage` этого браузера. Сервер и учётная запись не нужны.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки: `npm run build`. Vite берёт изображения из `../assets/memories` и копирует их в сборку рядом с приложением.

Чтобы использовать внешний каталог изображений, задайте `VITE_ASSET_BASE_URL` при запуске или сборке. Значение должно указывать на каталог с файлами WebP, например `https://example.com/memories/`.

Каталог карточек находится в `cards.json`. Поле `image` содержит только имя файла; адрес изображения централизован в `src/catalog.ts`.
